# RootQuest

**Make progress feel personal.** RootQuest is a calm, gamified personal-growth workspace for turning everyday priorities into meaningful quests and repeatable habits.

## What you can do

- Organize quests across Learning, Wellbeing, Creative, and Life admin.
- Complete quests to earn XP and keep your progress visible.
- Build weekly rituals and check them off day by day.
- Use the built-in 25-minute focus timer.
- Review a weekly activity overview and progress by domain.
- Search your quests from anywhere with `⌘ K` / `Ctrl K`.
- Update your profile name and keep your workspace across reloads.

Your workspace is saved in this browser with `localStorage`; no account or external service is required.

## Run locally

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Vite prints the local development URL after the server starts.

## Production build

```bash
npm run build
npm run preview
```

The production-ready static site is generated in `dist/`.
